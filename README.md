# SatQuery AI

Exploring satellite imagery analysis and remote sensing
through deep learning and computer vision.

## About

SatQuery AI is a research-oriented project focused on
building, training, evaluating, and experimenting with
deep learning models for geospatial and satellite imagery.

The project emphasizes model development, reproducible
experiments, quantitative evaluation, and practical inference.
